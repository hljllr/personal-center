# 个人数据中心

给所有 AI 对话用的个人上下文库。新开对话时，先让 AI 读这里的文件，省掉调教。

---

## 文件索引

| 文件 | 内容 | 什么时候读 |
|---|---|---|
| `个人画像.md` | 我的身份、交流习惯、做事方式、项目原则 | **每次都读** |
| `项目画像-生产跟单系统.md` | 生产跟单系统的完整上下文（业务、数据模型、坑、待办） | 聊这个项目时读 |

---

## 怎么让 AI 读

把 raw 链接直接贴进对话，说「先读这个」：

```
https://raw.githubusercontent.com/<你的用户名>/personal-center/main/个人画像.md
```

GitHub 上打开文件 → 右上角 **Raw** → 复制地址栏。中文文件名会被转成 `%E4%B8%AA...`，直接用也行。

**如果 AI 读不了链接**，就把文件内容整段贴进去。
